# UPI-Transaction-Dashboard-Power BI


Interactive dashboard to analyze bank transactions across Indian cities.

## Visuals
- Matrix Table – City-wise monthly Amount & Remaining Balance
- Column & Line Charts – Balance trends by Month

## Filters
City | Gender | Age Group | Bank | Payment Method | Transaction Type

## Tools
Power BI Desktop | DAX
